# Custom Prompt for Microsoft PowerShell Core

## Requirements
- [Microsoft PowerShell Core](https://github.com/powershell/powershell)
- [Any NerdFont](https://www.nerdfonts.com/#home)

## Installation
1. Set console font to any NerdFont
2. Copy `Microsoft.PowerShell_profile.ps1` to PowerShell profile directory. See [about_Profile](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_profiles)
